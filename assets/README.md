# Shared assets

Reusable source art and audio live here. Prototype-specific combat stats and behavior do not.

## Current state

No image or audio assets have been imported. The entries in `manifest.json` are planned assets, not existing files. POC 001 must remain usable with labelled shapes.

## First art pass

Seven static transparent creature tokens are planned: Ugallu, Girtablilu, Pazuzu, Warder, Censer, Harrier, and the Foundry Mechanism.

Suggested sources are 256 x 256 px for ordinary tokens and 512 x 512 px for the boss, in transparent PNG format. These are initial production suggestions rather than validated display requirements. Use one upright pose per creature; indicate facing separately in the interface.

- `tokens/`: shared creature token exports.
- `backgrounds/`: optional backgrounds, separate from gameplay geometry.
- `audio/`: optional temporary sound cues.

The board, links, threat zones, previews, ability buttons, and status indicators are generated by the prototype. No tile set, directional sprite sheets, custom font, or final music is needed.

## Registering an asset

Update `manifest.json` with the actual file path, creator/source information, permission or license information, and status when a real file is added. Do not mark missing files as available or infer a license.

Keep source files here. A prototype may import or copy explicitly selected assets into its local public/build folder when its build system is implemented. That copy/import step does not exist yet; a root asset is not automatically served by a prototype.

Do not introduce a shared asset pipeline until an implemented prototype needs one.
