# Agent scratch space

Keep intermediate outputs, exploratory scripts, hypotheses, and working notes here when they should survive a process or session. Contents are local and ignored by Git; this README is retained in Git.

Organize working files by task and worker as useful. Preserve results needed by another agent or future work in a [mailbox report](../../docs/mailbox/README.md) or the appropriate vault note before removing scratch files. No automatic cleanup is configured.

Follow [SCHEMA](../../docs/SCHEMA.md#agent-work-artifacts) for artifact lifetimes and promotion into durable records.
