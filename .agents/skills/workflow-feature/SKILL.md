# Feature workflow

## 1. Understand

Establish:

- desired outcome;
- scope;
- relevant constraints;
- acceptance conditions.

Use a Scout or Architect when investigation or design is required.

Do not repeat existing specification or design work when it is already adequate.

## 2. Plan

Identify bounded implementation tasks and their dependencies.

Run independent tasks concurrently when useful.

## 3. Implement

Assign implementation tasks to Implementers.

Each worker must receive:

- assigned scope;
- relevant context;
- acceptance conditions;
- expected handoff.

Record discoveries that affect other work.

## 4. Adapt

If implementation reveals that the current plan is wrong or incomplete:

- stop the affected work;
- update the relevant design or plan;
- propagate the discovery to affected workers.

Escalate changes to the requested product scope.

## 5. Verify

Run the project's relevant checks.

A worker saying that the task is complete is not verification.

## 6. Review

Use the review workflow when independent review is appropriate.

## 7. Complete

Report:

- implemented work;
- verification actually performed;
- review findings and disposition;
- important discoveries or decisions;
- remaining issues.
