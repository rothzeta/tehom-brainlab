# Playtests

Record experiment outcomes here, including tested commit, encounter and starting conditions, configuration overrides, observations, and limitations. Separate observations from interpretation and provisional tuning.

Use the [template](TEMPLATE.md) for a new report. No playtest results have been recorded yet.

Task execution and engineering checks belong in [TASK_LOGS](../TASK_LOGS.md); link to playtest reports when they provide acceptance evidence. A draft plan, unit-test pass, or browser smoke check is not a human playtest.
