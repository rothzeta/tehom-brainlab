# Lexicon

These terms describe the current Brainlab experiment and documentation. Game terminology is grounded in the [POC 001 brief](../prototypes/poc-001-linked-formation.md).

| Term | Meaning |
| --- | --- |
| Prototype / POC | An independent experiment testing a bounded game-design question |
| Brood | One of the three player-controlled creatures in POC 001: Ugallu, Girtablilu, or Pazuzu |
| Formation | The labelled Brood positions determined by shape and orientation |
| Compact | Three consecutive outer-ring cells |
| Spread | Three outer-ring positions approximately 120 degrees apart |
| Maneuver | A shared rotation or expansion/contraction; no independent movement or squad translation |
| Close / Stretched | Link classifications using the provisional distance threshold in the brief |
| Intention | An announced enemy action; area attacks commit to cells and targeted attacks follow a marked creature |
| Preview | A forecast using the same rules as a committed command without mutating live state |
| Experimental default | A provisional fixture or tuning choice requiring testing |
| Playtest | Observed gameplay recorded against a tested commit and explicit conditions |
| ADR | A decision record documenting an accepted obligation or explicitly marked proposal |
| Plan / task specification | Bounded intended work with an owner, acceptance criteria, and verification |
| Task log | Historical evidence of actual work and checks |
| Exploitation | Running and operating delivered prototypes and tools, including asset workflows and recovery |

See [CURRENT](../CURRENT.md) for implementation status and [SCHEMA](../SCHEMA.md) for document roles.
